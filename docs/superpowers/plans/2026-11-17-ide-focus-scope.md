# Уточнение объёма: надёжная индикация IDE

17 ноября 2026 пользователь выбрал «Узкий и надёжный плагин IDE» после
сравнения с готовыми RGB-проектами. Это уточнение ограничивает ранее утверждённый
[план развития](2026-11-16-product-evolution.md), сохраняя его архитектуру и интерфейсы.

## Цель

KGBoard достоверно отображает состояния IDE, явно объясняет отсутствие индикации
и безопасно завершает вывод. Поддержка устройства определяется возможностями его
режимов и фактическими испытаниями; отсутствие мерцания EVision не обещается.

## Сохраняемый объём

- E1 и A1–A4 выполнены; A5 завершается: назначения устройств, понятные сценарии,
  отдельные черновики приложения/проекта, Preview/Apply/Cancel и доступный нативный UI.
- B1–B3: единое решение о цвете, действительная доставка, ограниченная история,
  компактный статус и диагностика причины текущего вывода.
- C1–C3: корректная идентичность параллельных операций, optional SDK providers,
  достоверные состояния Git и проверяемые источники событий сборки. Непроверенные
  backend-события обозначаются как неподдержанные, а не успешные.
- E2: восстановление после сна и изменения часов без воспроизведения устаревших эффектов.
- E3: программная проверка существующих сценариев, native UI, отключённых optional
  providers, совместимости IDE и дистрибутива. Profile UI проверки исключены.

Порядок остаётся прежним: завершить A5, выполнить B и C, E2 после B2, затем
заключительную E3 и один свежий обзор всей ветки. Утверждённый inline-режим сохраняется.

## Отложено

D1–D3 не выполняются в этом этапе: библиотека шаблонов, пользовательские профили,
редактор различий профиля, новые каналы яркости и отдельная animation policy.
Для статичной индикации используется уже существующий эффект Static; новый механизм
профилей для этого не требуется. Существующие настройки и XML сохраняются.

Также не входят универсальный редактор анимаций, аппаратный backend, изменение
прошивки/драйвера и интеграция с Aurora/Artemis. Исследования остаются основанием
для последующих решений, а не заявлением о готовой совместимости.

## Критерии результата

1. Потеря фокуса, смена/закрытие документа, параллельные операции, Cancel,
   Disconnect, Disable, reconnect и shutdown имеют явные состояния и проверки.
2. Неизвестные факты не обозначаются успешным или чистым состоянием.
3. Диагностика объясняет тот же кадр, который получает единственный writer;
   завершённая запись SDK не выдаётся за аппаратное подтверждение.
4. Повторные статичные кадры объединяются, устаревшие назначения не получают запись.
5. Отчёт различает Passed/Failed/NotRun/Blocked; физическая проверка нового плагина,
   непроверенные ОС и русская native UI локализация остаются явно отмеченными.

Root AGENTS.md, диапазон SDK `263.*`, существующие storage names и запрет
автоматической публикации сохраняются. Новые runtime-библиотеки не добавляются.
