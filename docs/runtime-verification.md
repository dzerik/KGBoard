# Проверка runtime 3.0.0

Дата: 2026-11-16. SDK: IntelliJ IDEA Ultimate 2026.3, build263.7307.200.
JDK25, Kotlin2.4.21, Gradle9.7.0. Базовый коммит SDK: `21c7312`.

## Автоматическая проверка

- Полная JUnit Jupiter6 suite: 232 теста, 0 ошибок/пропусков; unit, управляемое время, TCP reset на локальном ServerSocket,
  coalescing при заблокированной записи, reconnect и смена геометрии через реальный writer.
- SDK fixtures действительно запускаются: selectionChanged/последний закрытый editor,
  initial dumb state, XML round-trip app/project/custom groups, настоящая Settings UI
  Apply/Cancel и незавершённое редактирование таблицы устройств.
- ZIP собирается командой `./gradlew test buildPlugin`.
- `./gradlew verifyPlugin --offline` проверяет ZIP против того же SDK без Marketplace.
  Результат: Compatible, без Internal/deprecated API usages. Ошибки Internal API не исключаются из правил verifier.
- Отдельно проверяется отсутствие старых compositor/connection/effect-manager paths
  и прямых LED-вызовов из bridge/settings. AGENTS.md сохранён без изменений.

## Аппаратная проверка

Физическое RGB-устройство в этой среде не предоставлено. Версии OpenRGB и клавиатуры
не определялись. Следующие сценарии на оборудовании **не проверены**:

| Сценарий | Статус |
|---|---|
| Первый Connect, имена устройств, выбранные LED | Не проверен |
| Test → Cancel/OK/Apply, повторный Test и Disconnect | Не проверен |
| Два окна проектов и закрытие фонового проекта | Не проверен |
| Одновременные Run/Debug/Test и отмена сборки | Не проверен |
| Потеря/возврат фокуса во время pulse и статичного эффекта | Не проверен |
| Изображение, отсутствие вкладок и смена документа | Не проверен |
| Реальный TCP reset/reconnect, исчезновение устройства, другой LED count | Не проверен |
| Завершение IDE и последний кадр resetOnExit | Не проверен |

Фейки и SDK fixtures подтверждают программные контракты, но не аппаратную совместимость.

## Сохранённые ограничения

Build наблюдается через ProjectTaskManager; независимые external-system сборки не добавлены.
Debug/search shortcut contexts определяются автоматически; editing/vcs требуют явной активации.
Git-индикатор сохраняет сравнение local/tracked hash без проверки направления расхождения.

## Итог независимого технического review

Review выполнен отдельным агентом по всему изменению. Исправлены три Important:
ошибки root/suite и незапущенные тесты больше не становятся успехом;
shortcut indices привязаны к поколению session/device mapping;
shutdown снимает preview и отправляет финальный reset также preview-only устройствам.
Регрессии воспроизведены тестами RED→GREEN; полная suite232/232.
Отложенных Minor замечаний технического review нет.

UX/UI проверен отдельным проходом; проблемы структуры существующих настроек и
предложение последующего редизайна находятся в [UX/UI-аудите](ux-ui-audit.md).
Runtime-рефакторинг не является заявлением, что этот редизайн уже выполнен.

## Принятые решения и цена

1. Работа выполнена в исходной feature-ветке с SDK checkpoint; отдельный worktree
   не создавался. Цена: изоляция ограничена этой веткой.
2. Terminal эффекты ограничены effectDurationMs независимо от цели. Цена: per-key
   ошибки больше не остаются включёнными бессрочно.
3. Проверенный неизменённый SDK baseline повторно использован. Цена: результаты
   baseline требуют перепроверки, если меняется SDK/checkpoint.
4. Probe выполняется каждые5с; изменения inventory открывают новую сессию. Цена:
   периодические SDK-запросы и короткое переподключение при смене оборудования.
5. ProjectRuntimeService отделён от ProjectRuntimeBinding. Цена: дополнительный
   небольшой класс связывания с SDK.
6. Явный Disconnect сохраняется при Cancel настроек. Цена: Cancel не восстанавливает
   соединение, которое пользователь сам отключил.
7. Writer сохраняет завершающий обычный кадр для ухода с живой сессии. Цена:
   дополнительная отправка на каждое ранее управляемое устройство.
8. Начальная сверка использует public RunContentManager.allDescriptors. Цена:
   завершённые descriptors приходится явно отфильтровывать.
9. Git сравнивает local/tracked hash по прежнему правилу. Цена: отставание локальной
   ветки тоже может показываться как unpushed.
10. Независимые external-system сборки не наблюдаются. Цена: для них нет подсветки.
11. editing/vcs shortcut contexts остаются явными. Цена: автоматической активации нет.
12. Устойчивый идентификатор устройства отложен. Цена: после переупорядочивания
    устройств OpenRGB сохранённый индекс может потребовать повторного выбора.
13. Аппаратная совместимость остаётся неподтверждённой. Цена: тесты не гарантируют
    поведение конкретной клавиатуры.
